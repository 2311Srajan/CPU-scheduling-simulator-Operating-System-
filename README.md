# CPU Scheduling Simulator

A C++ simulator that models core Operating System CPU scheduling algorithms and compares process performance metrics.

## Tech Stack & Data Structures
* **Language:** C++
* **Data Structures:** Queue, Priority Queue

## Key Features
* Implemented fundamental scheduling algorithms: First-Come, First-Served (FCFS), Shortest Job First (SJF), and Round Robin.
* Computes and displays critical performance metrics including average wait time and turnaround time.
* Handles process execution order modeling and edge cases for accurate process simulation.

## How to Run
1. Clone the repository: `git clone https://github.com/2311Srajan/CPU-scheduling-simulator-Operating-System-.git`
2. Compile the C++ program: `g++ main.cpp -o simulator`
3. Run the executable: `./simulator`
